📡 Network check

Open this page on a student iPad on the school Wi-Fi before class. It checks whether the game's message relays can be reached (secure WebSockets on port 443, the same kind of traffic as Kahoot).

Checking… ⏳

The game sends every message through all the relays at once and uses whichever arrives first, so it works if at least one relay is ✅. Two or more ✅ is best.
