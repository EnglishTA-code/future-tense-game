📡 Network check

Open this page on a student iPad on the school Wi-Fi before class. It checks whether the game server (Firebase) and the backup relays can be reached (secure WebSockets / HTTPS on port 443, the same kind of traffic as Kahoot).

Checking… ⏳

The game uses the game server (Firebase) first. The three backup relays carry the same messages, so a device that can't reach Firebase still plays over them. It works if at least one line is ✅; Firebase ✅ is best.
